# 公司基本面分析工具

在浏览器中分析美股与马股公司的基本面：录入多年财务数据，自动计算财务比率、绘制多年趋势图并提示风险。界面为简体中文，数据只保存在本机浏览器（localStorage）。

## 使用方法
1. 用浏览器直接打开 `index.html`（无需安装、无需联网）。
2. 点击「新增公司」，选择市场（美股 / 马股）、报表币种（USD / MYR）和金额单位。
3. 在「财务数据」表格中逐年录入数据，修改后自动保存。
   - 留空表示无数据，不会被当作 0。
   - 负数可写作 `-100` 或 `(100)`。
   - 金额与股数请使用同一单位（如都用「百万」），股价按每股实际价格填写。
4. 页面下方自动显示风险提示、财务比率和多年趋势图。
5. 用「导出 JSON」备份数据，用「导入 JSON」恢复。

想先看效果，可点击「载入示例数据」（两家虚构公司）。

## 计算的指标
毛利率、净利率、ROE、负债率、流动比率、经营现金流/净利润、自由现金流、EPS、市盈率、市值，以及营收、净利润、经营现金流、EPS 的同比增长。

当某个指标在当前数据下没有意义时（如亏损时的市盈率、股东权益为负时的 ROE），显示「—」并附说明，而不是给出误导性的数字。

## 风险提示规则
- 净利润增长但经营现金流下降
- 经营现金流/净利润连续两年低于 0.8
- 有盈利但自由现金流为负
- 负债率超过 70%，或一年内上升超过 10 个百分点
- 流动比率低于 1
- 营收增长但毛利率下降超过 3 个百分点
- 股东权益为零或负数
- 净利润由盈转亏
- 总股数增加超过 5%
- 最新年度市盈率超过 50 倍或亏损
